- Without --simulate this Agent observes only. With --simulate it additionally
answers discovery requests as a local simulated host, injected over loopback
only. Without --forward-to it never forwards to a peer (with --forward-to it does,
see the F3-A bullet below) and no mode ever modifies game traffic. F1 evidence
only - NOT a multiplayer, E2-B or Gate A result.
- F5 --sim-lan-listen: the LAN simulated host binds ALL discovery ports on the given
IP and answers real Civ6 discovery broadcasts directly (no Hook chain, no native
broadcast routing/metric/firewall dependence). It is a SIMULATED HOST seen by a
real client - evidence for the cross-machine discovery path, NOT a
two-real-hosts multiplayer result and NOT E2-B/E3. The Agent never binds :62056,
never sets SO_REUSEADDR.
- F2 --simulate-datapath: the 20B reply is a LOCAL PROBE ONLY (codex D4) - it does
not claim a real peer source port, a game protocol answer, Relay RTT, or that

- F3-A --forward-to/--forward-listen: a LOOPBACK PROTOTYPE. Payloads are forwarded

forward mapping key mirrors the civlink-fakeip crate shape but is a prototype
allocator; the crate remains the reference implementation.
