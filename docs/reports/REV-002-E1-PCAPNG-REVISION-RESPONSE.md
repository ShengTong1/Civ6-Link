## 1. R-1 字节序错误的根因与影响面

**根因**：解析器 v1 对 IPv4 Identification 使用
`[BitConverter]::ToUInt16($frame, $off)`（x86 小端），而 IPv4 ID 是网络字节序字段。
线上字节 `f6 e4` 应读作 **63108**，v1 读成 **58614** 一类值。

**后果**：相邻端口的高/低字节交换后差值被放大，产生"同轮不同端口恰好 +256"的
**系统性伪规律**，并被误当作"单次 sendmsg 循环中 100 次分配的连续序列"的证明。

**修正后实测（网络字节序，可复现）**

| 轮 | 数据报身份 | IP ID 区间 | 区间长度 | 实际个数 | 连续 |
|----|-----------|-----------|---------|---------|------|
| 1（Radmin 部分） | 99 | 63108 – 63206 | 99 | 99 | ✅ |
| 2 | 100 | 63207 – 63306 | 100 | 100 | ✅ |
| 3 | 100 | 63307 – 63406 | 100 | 100 | ✅ |
| 合计 | 299 | 63108 – 63406 | 299 | 299 | ✅ 无缺口无重叠 |

- 轮2、轮3 相邻间隔 **全部 +1**；轮1 为 98 个 +1 + 1 个 +3 469。
- Hyper-V 接口的 62900 身份 IP ID = **59639**（独立 IP ID 空间，8 条记录一致）。
- **接口/源地址差异未裁决**：轮1 端口 62900 这一个身份显示 Hyper-V 源（172.27.112.1 / 00:15:5d:91:c3:2e，IP ID=59639），其余 99 个显示 Radmin 源（26.74.126.98 / 02:50:ad:ad:4a:dd）。抓包只证明该数据报**呈现**的源地址不同；无证据表明它同时在 Radmin 序列分配过某 ID（「63107 缺失」「不同接口各自分配 ID 空间」两种说法**均已撤回**，列为 E2 待观察项）。
  本次抓包无法裁决（需路由表快照 + pktmon 捕获点元数据）。

**复核方给出的对照值核对**：复核称轮1 端口 62901 = 63108、62902 = 63109 —— 与本次重算
**同区间、同步长**（本次按端口顺序排列时 62900 走 Hyper-V，故 Radmin 段从 62901 起为 63108）。
62950 轮1 = 63157、62900 Hyper-V = 59639 亦与本次重算一致。**数字层面已对齐。**

**复现方法**（PowerShell 5.1，直接运行脚本；脚本为顶层脚本，**不导出函数**）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  .\CivLink-M0A-audit\scripts\analyze-pcapng-datagrams.ps1 `
  -Pcap .\M0A\captures\E1-pcapng-20261111_201146.pcapng `
  -OutCsv .\M0A\captures\E1-pcapng-datagrams.csv
```

控制台会直接打印：总 EPB、发现包匹配记录数、数据报身份数、轮数、逐轮端口完整性/跨度/源 IP 分布、
逐轮 IP ID 前十项与相邻差值分布、副本数分布、源地址（记录级/身份级）计数、源 IP × 源 MAC 交叉表。

**CSV 实际列（11 列）**：
`Round, PortOrder, DstPort, SrcIp, FirstMac, IpId, IpIdDelta, SrcPort, Copies, UniqueIpId, FirstTs`。
- `Round` = 轮次（间隔 > 100 ms 分轮）；`PortOrder` = `DstPort - 62900`；
- `IpIdDelta` = 同轮内按目的端口排序后与前一个身份的 IP ID 差（首项为空）；
- `Copies` = 该身份的捕获份数；`UniqueIpId` = 该身份内不同 IP ID 个数（归并键稳定性自检）。

**脚本编码要求**：脚本必须存为 **UTF-8 带 BOM**（`EF BB BF`）。本轮曾因写回时丢失 BOM 导致
`Unexpected token ')'` 等 3 个解析错误（PS 5.1 按 GBK 解码中文注释），重新加 BOM 后 `parse_errors=0`。

**旧解析器处置**：`C:\Users\dd\Desktop\civlink-run\parse-pcapng.ps1` **已退役**
（仓外不可复核 + 含小端缺陷）；E1 报告 §6 附录已改为"已退役"并指向入仓解析器。
