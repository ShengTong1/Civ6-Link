## 补丁 1：§3 步骤 0 换成预检（对应 P-5）

```
# 0) 预检：确认无残留 agent 占用发现端口（上轮未退干净会导致本轮 bind fail 或旧进程抢答，N-4）

改为：

```
# 0) 预检（必须，READY 才能继续）：
#    powershell -NoProfile -ExecutionPolicy Bypass -File .\run-m0e-preflight.ps1
#    退出码 0=PREFLIGHT: READY，2=ACTION NEEDED（按提示修完再跑），3=FATAL（读不到防火墙状态）
#    它覆盖：agent 入站 Allow 是否精确匹配"你要运行的那个 exe 路径"、是否覆盖本机在用的
