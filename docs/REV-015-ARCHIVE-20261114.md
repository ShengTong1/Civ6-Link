## 2. REV-015 中已被后续证据更新的部分

- §1.2「入向在'同 LAN 直连'下不需要任何 Hook」：B 级推理。F1 集成与 F2 S5 已把**出向 Hook 捕获发现广播 → Agent 单播回公告**的形态落地为真实代码与证据（F1 两轮 300/700 帧闭合；S5 真机 62056 出向观测），但"入向不需要 Hook"仍无独立跨机实验，维持 B 级。
- §1.4 `T_window` 与响应无关（A 级实测对照，2021.252/2018.945/2013.841 vs 2016.987/2024.513/2018.729 ms）：结论有效，未被后续实验推翻。
- §3.3 夹具条件清单（metric / 广播出口 / bind 源地址 / set-broadcast-path helper）：执行端 2026-11-13 已把 `METRIC-PRECONDITION` 降级为只读观测记录；metric 修改授权从未申请。维持。

## 3. 与 REV-016 的执行顺序衔接

- REV-016（`REV-016-SIMULATED-PEER-FAST-TRACK.md`）取代的是"等待第二台 Civ6 电脑"的执行顺序，**不取代** REV-015 提出的结构性疑问；REV-015 的价值在于是首个把"同 LAN 双人原生可用 → 产品增量是什么"显式化的文书。
