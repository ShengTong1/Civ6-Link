### A.2 两个 5 字节文件：独立验证"同哈希"的成因

任务书要求独立验证记录 §4 的说明。**记录的说法不成立**：

- 两文件实测字节 = `239,187,191,13,10` = `EF BB BF 0D 0A`，即 **UTF-8 BOM + CRLF**，**不是空内容**。
- 本轮同机复算三条：
  - `sha256(该 5 字节 EF BB BF 0D 0A)` = `F01A374E9C81E3DB89B3A42940C4D6A5447684986A1296E42BF13F196EED6295`（与交付一致）
  - `sha256(空，0 字节)` = `E3B0C44298FC1C149AFBF4C8996FB92427AE41E4649B934CA495991B7852B855`（**不等于** `F01A374E…`）
  - `sha256(空字符串经 `Out-File -Encoding utf8`)` = `F01A374E…`（同上，即真实成因）

结论：两文件同哈希**确实属预期**，但机制是 `PowerShell Out-File -Encoding utf8` 把空字符串写成 BOM+CRLF，**不是**记录 `:85` 所称"两文件都是 5 字节空输出……空内容的 SHA-256 相同"。**记录对成因的描述错误**（见 R3-M1）。

### B.2 三个指定检查点

**(1) 闭合恒等式断言是否可能因计数器同增同减而恒真 —— 不恒真，它是真断言。**

- 站点：`:272-275`，`$acct = fwd + skipNotDp + skipDisco + skipKey + ffail`，断言 `$acct -eq [int]$seen`。
- 为什么不是同增同减：`frames_seen` 在源码里由**两条互斥的代码路径**自增 —— `main.rs:729`（`consider()` 内，覆盖转发/跳过的全部分支）与 `main.rs:1400`（发现帧分支，根本不进 `consider`）。任何一条路径漏加，恒等式立刻破。**它是唯一同时约束两条路径的断言。**
- 已被实证：`150809` 的 `seen=6 / sum=7` 就是它命中的，`150906` 修好后 `seen=7 / sum=7`。本轮独立复算三个 run 的闭合性：`150809 close=False`、`150855 close=True`、`150906 close=True`。
- 结论：**真断言、有历史检出记录、非恒真。**

**(2) `peer first sender` 只比端口是否足以绑定"投递来自本 ForwardState" —— 不足。**

- 站点：`:290-292`。`$fwSock` 与 `$firstSender` 来自**同一份 `summary.txt`**（`:250`/`:251` 的 `Grab`），两者都由 Agent 自己打印；断言只比端口号、不比 IP、不跨文件。
- 它证明的只是"summary 内部两处回显一致"，不构成对 `forward-log` 的独立交叉验证。REVIEW-2 要求的三件事（跨文件读 `peer-recv … from=`、比 IP、断言端口 ≠ 62056）**一件都没做**。
- 更实际的问题：即使不看 summary，`forward-log.txt:3,5,8,10` 的 `peer-recv … from=127.0.0.1:58526` 与 `:2,4,7,9` 的 forward 行**本来就同源同进程**，回环原型下"发送者身份"天然只有一个候选，该断言的鉴别力上限很低。**弱断言，M7 未关闭。**

**(3) 按 seq 配对的断言能否抓到"载荷串位" —— 能。**

- 站点：`:335-357`。`$wantBySeqLen` 把 seq `1/2/5/6` 各自绑到 `(digest, len)` 二元组（`:336-339`），逐条 forward 行用 `:344` 的正则抽 `seq/len/sha256` 后**三元比对**（`:351`），并额外要求 `$fwdLines.Count -eq 4`（`:357`）。
- 为什么能抓串位：seq1 与 seq2 长度相同（都是 8）但摘要不同（`5a36d008…` vs `c793bc05…`），仅靠长度或集合比较可被互换骗过，三元组绑定后互换必失败；若出现 `unexpected seq` 也直接判失败（`:349`）。
- 残留：只校验 forward 侧，未同时校验 peer-recv 侧的 seq 配对；但 `:324`（两侧摘要集合相等）+ `:328`（与期望摘要集合相等）联合已能间接约束。**判定：真断言，能抓载荷串位。**
